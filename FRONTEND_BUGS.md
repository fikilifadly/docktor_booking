## Frontend Bugs

### FEB-001: Disabled Slots Clickable
- **Bug**: UI allows clicking on unavailable time slots.

### FEB-002: Weak Email Validation
- **Bug**: Accepts invalid emails like "user@".

### FEB-003: Errors Not Displayed
- **Bug**: Users see no feedback when booking fails.

### FEB-004: Past Dates Selectable
- **Bug**: Users can select past dates in the calendar picker.

### FEB-005: Stale Data After Cancel
- **Bug**: Appointment list does not update until page refresh.

### FEB-006: No Logout Confirmation
- **Bug**: Immediate logout on button click, poor UX.

### FEB-007: Appointment List Not Refreshed After Booking
- **Bug**: The newly booked appointment does not appear in the appointments list until the user manually refreshes the page.
